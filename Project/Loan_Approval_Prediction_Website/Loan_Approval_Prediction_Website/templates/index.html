PROJECT

Loan Approval Prediction Using Ensemble Machine Learning

The supplied project describes loan approval as a classification problem using applicant and financial information. The report emphasizes preprocessing, feature selection, ensemble learning and evaluation with accuracy, precision, recall, F1-score and a confusion matrix.

InputApplicant, income, loan and credit details
PreprocessImputation, scaling and one-hot encoding
ModelsLogistic, Decision Tree, Random Forest, Gradient Boosting
OutputApproved / Rejected + model-vote agreement
Academic use: This website demonstrates the uploaded project implementation. It is not a real lending or financial decision system.
